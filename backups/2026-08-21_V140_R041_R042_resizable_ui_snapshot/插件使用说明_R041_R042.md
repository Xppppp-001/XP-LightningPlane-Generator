# XP闪电面片生成器 V1.4.0 使用说明

适用软件：Autodesk 3ds Max 2023 中文版  
插件文件：`XP闪电面片生成器_V1.4.0.mzp`

## 1. 插件用途

本插件根据一个起点和一个或多个终点，生成写实噪波路径的连续带状闪电面片，并自动创建贴图通道 1 的 `0–1` UV。

主要功能：

- 一个起点可连接多个终点，每个终点生成一个独立的 Editable Poly 对象。
- 可指定每条分支的基础长度面数、额外长度面数和 `1～8` 横向分段；其他参数不会暗中加面。
- 路径噪波负责中心线弯折，轴向 Twist 负责面片截面旋转，两者互不替代。
- “整段朝向旋转”可把整条带状面片围绕中心路径转到合适朝向，不改变其他生成参数。
- 支持两端平滑收尖、起终点锁定、规则直带到最终模型的 FFD 式单次映射。
- 选中一个已生成面片后，修改参数会实时原位更新该对象。
- 每个面片可保存自己独立的有序途经点，并可选择共享切线的平滑过渡；中心线始终按列表顺序精确经过途经点中心。
- 途经点启用平滑时，内部转向区域保持用户设置的宽度；需要更多线环时由“额外加面”滑条统一控制。
- 只有点击“强制重新生成”才会新建对象，已有面片不会被覆盖。
- 自动生成沿起点到终点方向展开的 UV。
- 主窗口可自由调整宽度和高度；空间不足时自动显示滚动条，不必让整块长面板一直占满屏幕。

插件不再提供 Unity／Y-Up 轴向修改功能，也不会为新面片安装用于冻结旋转的 Rotation List。

## 2. 安装与启动

1. 启动 3ds Max 2023。
2. 将 `XP闪电面片生成器_V1.4.0.mzp` 从 Windows 资源管理器拖入 3ds Max 视口。
3. 插件打开“XP闪电面片生成器 V1.4.0”中文窗口。

也可以在 3ds Max 中选择“脚本 > 运行脚本”，然后打开同一个 `.mzp` 文件。

插件不需要额外 Python 包、渲染器或第三方插件。

窗口默认使用紧凑高度，不会一次展开全部控件。拖动窗口边缘可以调整宽度和高度；窗口比完整内容小时，右侧会按需显示 3ds Max 原生滚动条，滚动后可操作底部的 Twist、锁端和“强制重新生成”等控件。把窗口放大到足够高度后，滚动条会自动隐藏。窗口缩放和滚动只影响界面显示，不会修改当前面片、参数、选择或实时更新目标。

## 3. 推荐工作流程

### 第一次生成

1. 在场景中准备一个起点对象和至少一个终点对象。
2. 点击“拾取起点”，选择起点对象。
3. 点击“添加终点”，依次加入一个或多个终点对象。
4. 设置平面面数、额外加面、宽度、噪波、Twist、收尖和端点锁定参数。
5. 点击“强制重新生成”。
6. 插件为终点列表中的每个终点创建一个新的 `LightningPlane###` 对象。

仅仅拾取起点、添加终点或修改面板参数不会自动创建第一批模型；新建模型必须点击“强制重新生成”。

### 编辑已有面片

1. 在场景中单独选中一个插件生成的 `LightningPlane` 面片。
2. 面板会自动载入该面片保存的起点、终点和全部生成参数。
3. 调整任意生成参数。
4. 等待约 `200 ms`，插件会自动原位更新当前选中的面片。

原位更新保持同一个场景节点，不改变对象名称、父子层级、Transform、轴心、材质和选择状态，也不会生成新编号。

如果同时选中了多个插件面片，参数不会更新任何模型。多终点强制生成后整组通常处于选中状态，因此继续调参前请先只选中其中一条分支。

### 给已有面片添加途经点

1. 在场景层级或视口中只选中一个已生成的 `LightningPlane`。
2. 在“所选面片途经点”中点击“添加途经点”，拾取普通场景对象。
3. 重复添加后，使用“上移”“下移”调整经过顺序，或使用“移除所选”“清空全部”管理列表。
4. 需要减弱硬折角时勾选“启用途经点平滑过渡”，再拖动“途经点过渡强度”滑条调整圆滑程度。
5. 需要更多圆滑细节时，拖动“额外加面”滑条；最终面数始终等于“平面面数 + 额外加面”。
6. 每次操作都会立即原位更新当前面片；不会改名、另建对象或影响其他面片。

途经点对象添加后仍可在场景中移动。移动完成后重新唯一选中它所属的 `LightningPlane`，插件会比较上一次成功生成时保存的控制点坐标；只有坐标确实变化时才经过约 `200 ms` 防抖并自动原位同步。坐标没有变化时反复切换层级不会重建模型。

路径顺序固定为“起点 → 途经点列表顺序 → 终点”。每个途经点取对象的世界包围盒中心，中心线在对应截面精确经过该中心。途经点只重定向整体基础走向，不新增或重置噪波、Twist、宽度、收尖、锁端、种子、UV 等参数。

“平面面数”是整条路径长度方向的基础段数，“额外加面”是用户明确追加的段数。最终长度面数严格为两者之和，插件按各段基础长度分配这些固定线环并为每个途经点保留一个精确截面。因此 `M` 个途经点要求两项之和至少为 `M+1`；不足时更新会被拒绝，原面片和原途经点列表均保留。噪波、Twist、途经点平滑和非共面程度不会暗中改变这个数量。

### 再生成一套新面片

需要保留当前模型并制作另一版时，再次点击“强制重新生成”。插件会保留所有已有面片，并按当前面板中的起点、终点列表和参数另建一组对象。

选择某条已有面片时，面板终点列表会切换为该面片自己的单个终点。如果需要重新生成多终点组，请先把其他终点重新添加到列表中。

## 4. 起点与终点面板

插件使用所选对象的世界包围盒中心作为控制点位置。插件生成的 `LightningPlane` 不能再次被拾取为起点或终点。

| 面板项目 | 作用 |
| --- | --- |
| 位置取自所选对象的世界包围盒中心 | 提示起点和终点取值方式。 |
| 拾取起点 | 从视口拾取一个对象作为公共起点。设置成功后按钮显示对象名称。 |
| 清除起点 | 清除面板当前起点，但不删除、修改或重新生成任何已有面片。 |
| 添加终点 | 每次拾取一个终点，可重复操作以加入多个不同对象。 |
| 终点列表 | 显示当前用于下一次强制生成的终点对象。 |
| 移除所选终点 | 从列表移除当前条目，不修改任何已有面片。 |
| 清空全部终点 | 清空列表，不删除任何已有面片。 |
| 有效终点／预计四边面 | 显示有效终点数和下一次强制生成的预计总数，即“（平面面数 + 额外加面）× 横向分段 × 终点数”。 |

以下情况会被拒绝并显示中文提示：

- 起点对象同时被用作终点；
- 重复添加同一个终点；
- 起点与终点中心重合；
- 两个终点的中心位置重合；
- 起点或终点对象已被删除或失效。

## 5. 模型参数

| 参数 | 范围与默认值 | 说明 |
| --- | --- | --- |
| 平面面数 | `1–1000`，默认 `24` | 规则直线 Plane 沿长度方向的基础四边面数量。 |
| 额外加面 | `0–1000` 的整数滑条，默认 `0` | 由用户明确增加长度方向四边面。最终纵向面数严格等于“平面面数 + 额外加面”；基础 10、额外 0 就是纵向 10 面。 |
| 横向分段 | `1–8` 的整数参数，默认 `1` | 宽度方向的四边面列数。单支总四边面数严格为“（平面面数 + 额外加面）× 横向分段”。设为 `2` 时会产生真实的 UV 中线 `V=0.5`；提高数值可减轻隐藏三角插值锯齿，但会按比例增加总面数。 |
| 闪电宽度 | `0.001–1000000.0` 世界单位，默认 `3.0` | 带状面片的总宽度。除主动启用的首尾收尖外，每一组横截面都精确保持此宽度；噪波、途经点、Twist 和整段朝向均不能修改宽度。 |
| 面片两端平滑收尖 | 默认关闭 | 开启后，起点和终点附近平滑缩窄；端点保留正常宽度的 `1%`，避免左右顶点完全重合产生退化面。 |

平面面数为 `1` 且启用收尖时，没有中间截面表现渐变，因此会生成一张两端都为正常宽度 `1%` 的窄四边面。

## 6. 所选面片途经点

| 面板项目 | 作用 |
| --- | --- |
| 添加途经点 | 先唯一选中一个 `LightningPlane`，再拾取一个普通场景对象作为该面片的新途经点。 |
| 途经点列表 | 显示当前所选面片自己的有序列表；切换选中面片时会载入另一面片保存的列表。 |
| 上移／下移 | 调整所选途经点在整条路径中的先后顺序，并立即原位更新该面片。 |
| 移除所选 | 删除当前列表项并立即原位更新。 |
| 清空全部 | 清除当前面片的全部途经点，使基础走向恢复为起点到终点。 |
| 启用途经点平滑过渡 | 默认关闭。开启后，相邻路径段在途经点使用共享切线形成连续圆滑转折；中心线仍精确穿过途经点中心。 |
| 途经点过渡强度 | `0–100` 的可拖动滑条，默认 `50`。`0` 与关闭完全等价，数值越高圆滑效果越明显。拖动时按约 `200 ms` 防抖实时更新。 |
| 纵向／横向／总面数提示 | 显示“纵向 L × 横向 M = 总计 L×M 面”。途经点平滑强度只改变导向曲线，不改变 L 或 M。 |

不同面片的途经点、平滑开关、过渡强度、额外加面和横向分段值完全独立。每个含途经点的面片会保存上次成功生成时的起点、途经点和终点中心快照；移动途经点后重新选中该面片会自动按最新中心同步。旧版有途经点但没有坐标快照的面片会在首次重新选中时兼容同步一次；旧版没有额外加面属性时按 `0`、没有横向分段属性时按 `1` 兼容。“强制重新生成”创建的新面片也从空途经点列表开始，不会复制当前所选面片的途经点。

平滑算法只处理起点、途经点和终点构成的基础导向曲线，并让相邻段共享同一条切线。路径噪波和轴向 Twist 始终按整条分支的全局 `0–1` 参数连续计算，不会在途经点重置、缩放、衰减或旋转。为了让最终中心线仍精确经过途经点，插件会在基础导向控制点层反向预补偿该位置原本就存在的全局噪波，再原样叠加噪波场；因此途经点处的噪波不会被强制压成零，Twist 累计角也不会重新开始。关闭平滑或把强度设为 `0` 时只把基础导向恢复为逐段直线。所有效果只变形“平面面数 + 额外加面”建立的固定规则 Plane。

## 7. 路径噪波

路径噪波改变闪电中心线的位置和弯折形状，它不是轴向 Twist。

| 参数 | 范围与默认值 | 说明 |
| --- | --- | --- |
| 路径噪波强度 | `0.0–1000000.0` 世界单位，默认 `15.0` | 控制中心线偏离起终点直线的幅度；设为 `0` 时不添加路径噪波位移。 |
| 噪波大小 | `0.01–100.0`，默认 `1.0` | 噪波整体尺寸倍率。数值越大，位移更明显，弯折通常更宽缓。 |
| 噪波 Tiling | `0.01–1000.0`，默认 `1.0` | 控制噪波重复频率；数值越大，弯折越密集。 |
| 噪波相位位移 | `-10000.0–10000.0`，默认 `0.0` | 沿路径推进或后退同一个确定性噪波图样，不移动起点、终点、途经点或整个模型。锁定端点仍精确穿过控制点。 |
| 分开控制噪波轴向强度 | 默认关闭 | 关闭时使用一个统一倍率控制世界 X/Y/Z；开启时改用三个独立倍率。切换模式只改变噪波位移分量，不改变基础路径、宽度、Twist 或整段朝向。 |
| 统一轴向强度 | `0.0–100.0`，默认 `1.0` | 同时乘到世界 X、Y、Z 三个噪波位移分量；`0` 会关闭全部噪波位移，但不改写“路径噪波强度”。 |
| X／Y／Z 轴强度 | 各 `0.0–100.0`，默认 `1.0` | 仅在分开控制模式可编辑。某轴设为 `0` 即完全关闭该世界轴上的噪波分量，另外两轴不受影响，因此可实现单轴噪波。 |
| 随机种子 | `-1000000–1000000`，默认 `1` | 改变确定性的随机形状。相同控制点、参数和种子会复现相同结果。 |

## 8. 整段轴向扭转（Twist）

Twist 围绕闪电中心线的局部切线轴旋转面片宽度方向，只改变截面朝向，不会用额外 Noise 移动中心线。

插件先在拉直的 `0–1` 逻辑长度中计算旋转，再通过最小旋转／平行运输框架映射回弯曲中心线，形成类似 FFD 的连续效果，避免路径曲率放大用户输入角度。

| 参数 | 范围与默认值 | 说明 |
| --- | --- | --- |
| 启用整段轴向扭转（Twist） | 默认关闭 | 开启后启用下面两个 Twist 参数；关闭或角度为 `0°` 时不施加额外轴向旋转。 |
| 轴向扭转分段 | `1–100`，默认 `4` | 数值记为 `K`，将全长等分为 `K+1` 份。前 `K` 份各累计一次所设角度，最后一份负责保持累计角或处理终点锁定回正；不会改变“平面面数 + 额外加面”的固定拓扑。 |
| 轴向扭转角度 | `-36000.0°–36000.0°`，默认 `90.0°` | 每个有效扭转分段的角度增量，正负值代表相反方向。未锁定终点时，总累计量为 `K × 角度`。 |
| 整段朝向旋转 | `-180.0°–180.0°`，默认 `0.0°` | 完全独立参数，每个截面都只增加同一个旋转角，用于整体调整带状面片朝向。它不会移动中心线、修改途经点、改变或缩小宽度、改变面数／UV／轴心或改名。 |

例如分段为 `2` 时，全长被分为三等份：前两份各累计一次输入角度，第三份保持最终角度；如果锁定终点，第三份按最短等价角平滑回正。

每个有效区间内部使用连续的恒定角速度，不会把“分段”仅当作细分精度，也不会增加随机摆动。

## 9. 起点和终点锁定

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 锁定起点 | 开启 | 起点处的路径噪波位移和轴向 Twist 角度精确为零，并在起点附近平滑衰减。 |
| 锁定终点 | 开启 | 终点处的路径噪波位移和轴向 Twist 角度精确为零；Twist 在最后一个等长区间按最短等价角回正。 |

关闭相应锁定后，路径噪波和 Twist 可以影响该端点。平面面数为 `1` 且两端都锁定时，只有起终点两组截面，Twist 不会产生可见效果。

面数小于或等于 `5` 时，离散线环可能不足以完整表现端点附近的平滑衰减，状态栏会给出提示。

## 10. 实时更新规则

以下参数支持约 `200 ms` 防抖实时更新：

- 平面面数；
- 额外加面滑条；
- 闪电宽度；
- 面片两端平滑收尖；
- 路径噪波强度、噪波大小、Tiling、相位位移、统一／分轴强度和随机种子；
- Twist 开关、分段和角度；
- 整段朝向旋转；
- 锁定起点和锁定终点；
- 途经点平滑开关和过渡强度滑条。

实时更新必须有一个有效的编辑目标：场景选择中只能包含一个插件生成面片。没有选中有效面片或选中了多个插件面片时，面板数值会保留，但不会新建、删除或修改模型。

拾取、清除起点，以及添加、移除或清空终点，只改变下一次强制生成所使用的控制点列表，不会自动更新已有模型。

途经点操作不同：它只对当前唯一选中的已有面片生效，并在添加、排序、移除或清空后立即原位更新该面片。移动途经点对象后重新选择所属面片，也会在检测到中心坐标变化时自动同步；未变化时不会重复更新。

更新成功时只替换所选节点内部的 Editable Poly 基础几何。更新失败时，所选节点的旧几何、名称、层级、Transform、轴心、材质和参数都会保留，其他面片始终不受影响。

## 11. 强制重新生成

“强制重新生成”是唯一会创建新 `LightningPlane` 对象的操作。

- 使用面板当前起点、全部终点和全部参数创建一套新对象。
- 每个终点生成一个独立 Editable Poly 对象，不合并分支。
- 已有新组和历史面片全部保留，不覆盖、不删除、不改名。
- 多终点采用整组原子新建：全部分支成功才提交；任一分支失败时不创建任何新分支。
- 每次点击都会新增一组，所以连续点击会让场景中的面片数量持续增加。
- 操作作为一次 Undo 步骤提交。
- 新建面片的途经点列表为空，不复制任何历史面片的途经点。

强制生成需要有效起点和至少一个有效终点。失败时会弹出中文原因，并在状态栏提示原模型已保留。

## 12. 输出对象、名称、轴心和 UV

### 独立对象与名称

- 每个终点对应一个独立 Editable Poly 对象。
- 新对象依次命名为 `LightningPlane001`、`LightningPlane002`、`LightningPlane003`……。
- 参数实时更新在原节点上完成，不改变名称或递增编号。
- 用户手动改名后再次编辑，仍保留自定义名称。
- 删除或新增面板终点不会重命名任何已有对象。

### 轴心

每个分支对象的轴心世界位置始终位于公共起点中心。插件只保证轴心位置，不修改轴心方向，也不执行 Unity／Y-Up 转换。

### UV

- 使用贴图通道 1。
- 每个独立分支占满自己的一套 `0–1` UV，可复用同一张闪电贴图。
- U 方向沿闪电长度：起点为 `U=0`，终点为 `U=1`。
- V 方向横跨面片宽度：横向索引 `j` 的 V 值为 `j/横向分段`，均匀覆盖 `0～1`；横向分段为 `2` 时列值为 `0、0.5、1`。
- U 值按实际弧长连续分布；实际面数或参数改变后会自动重建。
- 几何面和贴图面的数量及索引保持匹配，不需要手动展开或修复 UV。

## 13. FFD 单次生成与规则布线

每条分支只执行一次最终几何构建：

1. 计算最终纵向面数 `L = 平面面数 + 额外加面`，读取用户横向分段 `M`。
2. 在逻辑空间建立 `L × M` 的规则二维 Plane，共 `(L+1) × (M+1)` 个顶点；每个横向顶点都在同一截面左右端点之间线性插值。
3. 用连续中心导向曲线决定每组截面的中心位置；用最小旋转平行运输决定基础朝向；Twist 和整段朝向只旋转截面；收尖只缩放首尾宽度。这些效果一次映射到固定 Plane，不修改拓扑。
4. 比较整条分支两种候选对角线的最差质量，选择一个全局方向并用于所有四边面；这只影响内部三角显示。
5. 一次创建最终 Editable Poly 和一一对应的 UV。构建完成后不会循环补面、自动增加横向列或重新生成。

这一规则带来以下保证：

- 关闭收尖时，每组左右顶点距离都精确等于“闪电宽度”；途经点、噪波、Twist 和整段朝向不会暗中缩窄内部截面。
- 只有用户调整“平面面数”或“额外加面”才会改变纵向段数；只有用户调整“横向分段”才会改变宽度列数。
- 同一分支所有四边面使用同一个内部显示对角线方向，避免 Max／FBX／Unity 三角化后让贴图主线形成连续锯齿。
- 所有几何面使用平滑组 1；U 按最终中心线弧长从 `0` 到 `1`，V 覆盖 `0～1`，几何面与贴图面逐一匹配。
- 急弯允许左右边界出现连续的自然拉伸差，这是规则直带经过 FFD 式弯曲后的正常结果；不会再把这种差异误报为破面。

只有输入或 3ds Max 基础创建本身无效时才拒绝更新，例如控制对象失效、相邻控制点重合、数值非法、最终中心曲线出现零长度区间，或顶点／UV 创建 API 失败。失败时仍原子保留旧节点、旧几何与参数。

## 14. 常见问题

### 为什么“添加途经点”按钮不能点击

途经点属于已有面片，不属于下一次强制生成的共享控制点。请先在场景层级或视口中只选中一个有效 `LightningPlane`，按钮才会启用。

### 添加途经点后更新失败

先检查“平面面数 + 额外加面”是否至少为“途经点数量 + 1”，再检查途经点是否失效，或是否与前一个控制点／终点中心重合。失败时旧几何与旧列表不会改变。

### 移动途经点后面片没有变化

移动完成后，在场景层级或视口中重新唯一选中该途经点所属的 `LightningPlane`。插件会自动比较控制点坐标并原位同步。如果状态栏提示上次自动同步失败，请检查“平面面数 + 额外加面”是否至少为“途经点数量 + 1”、控制对象是否有效，以及相邻控制点中心是否重合；相同失败坐标不会连续重复重建。

### 调整参数后没有变化

请在场景中只选中一个有效的 `LightningPlane`。未选中插件面片或同时选中多个插件面片时，参数只会保留在面板中，不会修改模型。

### 设置起点和终点后为什么没有自动生成

这是当前设计。起点和终点只定义下一次新建使用的控制点，必须点击“强制重新生成”才会创建对象。

### 点击“拾取起点”后提示第 84 行 undefined

这是早期 V1.1.0 包在干净 3ds Max 会话中的函数定义顺序问题。请关闭旧插件窗口，重新拖入当前的 `XP闪电面片生成器_V1.4.0.mzp`；修复包不依赖旧会话中的全局函数，可以直接拾取普通场景节点。

### 多终点生成后为什么不能直接调参

强制生成完成后，多条新分支会一起被选中。实时编辑只接受一个插件面片，请先单独选中需要修改的那一条。

### 为什么选中已有面片后终点列表只剩一个

每条分支保存自己的起点和一个终点。选中面片时，面板会载入该对象自己的控制点，因此终点列表显示该分支对应的单个终点。这不会删除其他场景面片。

### Twist 看起来没有效果

- 确认已启用“整段轴向扭转（Twist）”；
- 确认轴向扭转角度不是 `0°`；
- 增加平面面数以提高旋转采样；
- 平面面数为 `1` 且两端锁定时不会产生可见 Twist。

### 为什么急弯处宽度变窄

V1.4.0 的 FFD 单次生成主链中，所有内部截面都保持用户设置宽度；噪波、途经点、Twist 与整段朝向都不能触发缩宽。只有主动启用“面片两端平滑收尖”时，真实起点与终点才会缩小。如果仍看到旧式收窄，请重新拖入当前 V1.4.0 MZP，并让所选面片完成一次原位更新。

### 极端弯折会自动增加面数吗

不会。纵向面数只等于“平面面数 + 额外加面”，横向列只等于“横向分段”。噪波、Twist、途经点、整段朝向和非共面程度都不能暗中增加。需要长度方向更平滑时调整“额外加面”，需要真实 UV 中间纵向边时提高“横向分段”。

### 为什么以前贴图里会看到三角形锯齿

四边面在 3ds Max、FBX 和 Unity 内部最终都会拆成两个三角形。宽度只有一列时，贴图中间轮廓完全依赖非共面四边面的隐藏对角线插值，可能显出锯齿。当前版本让整条分支只使用一个统一对角线，并提供完全由用户控制的“横向分段”：设为 `2` 会添加真实 `V=0.5` 纵向边，设为更高值会继续细分宽度；总面数严格按公式增加，不会从 10 面暗中膨胀到数百面。该功能不能修复贴图源文件自身的低分辨率、压缩锯齿或渲染过滤问题。

### 为什么强制重新生成后对象越来越多

这是按钮的预期行为：每次点击都会保留旧对象并创建一套新对象。日常调整已有模型时，应单独选中目标面片并直接修改参数。

### FBX 仍提示 Unsupported controller

当前版本不再创建 Unity/Y-Up 轴向按钮或 Rotation List。旧版本已经执行过轴向修改的历史节点不会被静默迁移，因此仍可能保留旧 Rotation List。请使用当前版本“强制重新生成”得到新的面片，再导出新对象。

## 15. 当前限制

- 不自动创建 V-Ray、Corona、Arnold 或其他特定渲染器材质。
- 不包含闪电贴图、发光着色器、动画、电流流动或自动生长效果。
- 不生成体积闪电，也不依赖第三方插件。
- 不包含未经确认的递归小分叉系统。
- 固定规则 Plane 不执行自动补面或全局空间自相交消除；极端参数的表现精度由用户设置的总面数决定。
- 插件只保证轴心位于起点，不提供轴心方向修改、Unity 轴向转换或旋转归零。
- FBX 导出器和 Unity Import Settings 仍需按项目自身流程设置。
- 途经点引用场景对象句柄；删除被引用的途经点对象后，后续更新会被拒绝并保留旧面片，插件不会猜测替代位置。
