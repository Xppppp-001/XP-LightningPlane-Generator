# XP闪电面片生成器

面向 Autodesk 3ds Max 2023 中文版的 MaxScript 工具，可从一个起点生成通往多个终点的带状闪电模型，并自动创建从左到右的 UV。

项目采用 [MIT 开源许可证](LICENSE)。扩宽工具 V1.2.0：[发布页](https://github.com/Xppppp-001/XP-LightningPlane-Generator/releases/tag/ribbon-v1.2.0) · [直接下载 MZP](https://github.com/Xppppp-001/XP-LightningPlane-Generator/releases/download/ribbon-v1.2.0/XP-Ribbon-Widener_V1.2.0.mzp)。

## 安装与启动

另有独立的 **XP模型扩宽工具 V1.2.0**：把 `dist/XP模型扩宽工具_V1.2.0.mzp` 拖入 Max，选规则四边面带状 Editable Poly 的横向边后，自动补齐整排并保持中线扩宽；支持首尾宽度倍率渐变，保留原 UV 数据。详见 [模型扩宽工具使用说明](模型扩宽工具使用说明.md)。构建命令为 `powershell -ExecutionPolicy Bypass -File tools/build-ribbon-widener.ps1`；隔离后台测试入口 `tools/test-ribbon-widener.ps1` 固定使用用户指定的 `C:\Program Files\Autodesk\3ds Max 2023\3dsmax.exe`。

1. 构建后取得 `dist/XP闪电面片生成器_V1.4.0.mzp`。
2. 启动 3ds Max 2023。
3. 将 `.mzp` 文件从资源管理器直接拖入 3ds Max 视口。
4. 中文工具窗口会以紧凑尺寸自动打开，不需要安装第三方依赖。窗口宽度和高度都可拖动调整；空间不足时会自动出现滚动条，向下滚动即可访问全部参数。

也可以通过 3ds Max 的“脚本／运行脚本”选择同一个 `.mzp` 文件。

## 基本使用

1. 点击“拾取起点”，选择一个场景对象。插件使用对象的世界包围盒中心作为起点。
2. 点击“添加终点”，逐个选择一个或多个场景对象；同一对象不会重复加入。
3. 设置“平面面数”“额外加面”和“横向分段”，再调整宽度、路径噪波强度、噪波大小、Tiling 和随机种子；需要尖头轮廓时启用“面片两端平滑收尖”。
4. 根据需要启用“锁定起点”和“锁定终点”。
5. 点击“强制重新生成”创建一套新的独立 Editable Poly 闪电对象；每个终点对应一个对象，依次命名为 `LightningPlane001`、`LightningPlane002`……。
6. 在场景中选中一个已有闪电面片后调整参数，只会原位更新该对象并保留名称、层级和轴心；未选中的面片不会改变。
7. 需要改变某条已有面片的整体走向时，唯一选中它，再用“添加途经点”及上移、下移、移除、清空操作管理该面片自己的有序路径；需要圆滑转折时启用“途经点平滑过渡”，拖动强度滑条。需要更多线环时由“额外加面”滑条明确增加。之后移动途经点对象并重新选中所属面片，会在坐标确实变化时自动原位同步。

窗口默认不再占满全部面板高度。可拖动四周边缘调整大小；缩小时使用右侧滚动条访问下方参数，扩大到足以容纳内容时滚动条会按需隐藏。调整窗口只改变界面显示范围，不会改变模型或任何生成参数。

## 参数说明

- 平面面数：规则直线 Plane 沿长度方向的基础四边面数。
- 额外加面：`0–1000` 整数滑条，默认 `0`。最终纵向面数严格等于“平面面数 + 额外加面”；噪波、途经点、Twist、整段朝向和非共面程度都不会暗中改变它。基础 10、额外 0 时就是纵向 10 面。
- 横向分段：`1–8` 的整数参数，默认 `1`。它只控制宽度方向的四边面列数；单支总四边面数严格为“（平面面数 + 额外加面）× 横向分段”。设为 `2` 时会生成真实的 UV 中线 `V=0.5`，可减轻单列非共面四边面隐藏对角线造成的贴图锯齿。插件不会自动修改该值。
- 闪电宽度：带状面片的总宽度。
- 面片两端平滑收尖：将每条分支的起点和终点平滑缩小到正常宽度的 1%，中段保持原宽度。端点保留极小宽度以避免退化面；平面面数为 1 时只会得到一张窄而有效的四边面。
- 路径噪波强度：细噪波使中心线偏离起终点直线的幅度；它不等于轴向 Twist。
- 噪波大小：噪波整体尺寸倍率；越大时位移更明显，弯折也更宽缓。
- 噪波 Tiling：噪波重复频率；越大弯折越密集。
- 随机种子：相同控制对象、参数和种子会复现相同模型。
- 启用整段轴向扭转（Twist）：先在拉直的逻辑带上做类似 FFD 的累计旋转，再通过最小旋转平行运输框架映射回细噪波中心线，不给中心线增加额外 Noise，也不会让路径曲率放大角度。
- 轴向扭转分段：数值 `K` 将整条逻辑长度等分为 `K+1` 份；前 `K` 份是有效旋转段，最后一份用于终点保持或锁定回正，不改变“平面面数”。例如 2 段就是三等分。
- 轴向扭转角度：表示每个有效旋转段的角度增量；未锁定终点时总累计量为“分段数 × 角度”。每段使用恒定线性角速度，正负值代表相反方向，设为 0 等同于关闭。
- FFD 单次生成：插件先建立长度为“平面面数 + 额外加面”、宽度为用户“横向分段”的规则二维 Plane 和规则 `0–1` UV，再把中心路径、平行运输截面、Twist、整段朝向与收尖一次映射到最终 Editable Poly。FFD 是内部变形方法，不是额外的自动分段参数。
- 锁定起点／终点：锁定处的路径噪波位移和轴向 Twist 角度精确归零，并在端点附近平滑衰减。
- 所选面片途经点：每个面片独立保存对象句柄和上次成功控制点坐标快照，路径按“起点 → 列表顺序 → 终点”精确经过各对象中心。移动途经点后重新选择所属面片时，只有检测到坐标变化才经过防抖原位更新；它不改变噪波、Twist 或其他参数，“平面面数 + 额外加面”至少需要“途经点数量 + 1”。
- 启用途经点平滑过渡：默认关闭；开启后用相邻段共享切线的平滑曲线消除途经点处的硬折角，仍精确经过途经点中心。
- 途经点过渡强度：范围 `0–100` 的滑条，默认 `50`。`0` 与关闭完全等价，数值越高整体走向越圆滑；只改变基础路径，不改写噪波、Twist、宽度、收尖、锁端、种子或 UV 参数职责。
- 途经点只控制导向：整条分支始终使用同一套全局噪波场和 Twist 累计角，不在途经点重置、衰减或旋转。插件在基础导向控制点层反向预补偿全局噪波，因此最终中心线仍精确经过途经点，但途经点处的噪波不会被强制压成零。
- 四边面对角线：每条独立分支只选择一个全局对角线方向用于全部四边面。对角线只影响 Max／FBX 的内部三角显示，不改变用户设置的纵向或横向分段。
- 贴图稳定：截面由最小旋转平行运输连续建立，所有面统一使用平滑组 1；UV 的 U 按最终中心线弧长分配，V 按横向分段从 `0` 均匀到 `1`。急弯允许内外边出现连续的自然拉伸差，但截面宽度不会变窄。
- 多途经点切线稳定：首尾同时局部加密的中间段按相邻实际边的单位方向公平分角；平行运输与 Twist 共用同一切线，第二个途经点不会因为两侧线环间距不同而额外扭转截面。

选中单个已有闪电面片后，数值、随机种子、锁定选项、两端收尖和轴向 Twist 参数会实时更新该对象的几何与 UV。拾取或更换控制点、添加或移除终点只影响下一次“强制重新生成”，不会修改已有面片。

强制重新生成与普通实时更新是两种不同操作：前者保留旧对象并新建一组，后者只原位更新场景中当前选中的单个插件面片。插件不再提供 Unity／Y-Up 轴向修改功能，也不会为新面片安装用于冻结旋转的 `Rotation List`。

## UV 与轴心

- UV 使用贴图通道 1。
- 每条分支按实际弧长从起点 `U=0` 展开至终点 `U=1`，宽度方向为 `V=0–1`。
- 手动增加长度线环或横向分段后会重建规则 UV；U 仍按最终弧长从 `0` 到 `1`，V 按横向列均匀覆盖 `0–1`。
- 每个独立分支对象都占满自身的 `0–1` UV，可复用同一张闪电贴图。
- 输出对象轴心始终位于公共起点中心。
