# XP闪电面片生成器

面向 Autodesk 3ds Max 2023 中文版的 MaxScript 工具，可从一个起点生成通往多个终点的带状闪电模型，并自动创建从左到右的 UV。

## 安装与启动

1. 构建后取得 `dist/XP闪电面片生成器_V1.2.0.mzp`。
2. 启动 3ds Max 2023。
3. 将 `.mzp` 文件从资源管理器直接拖入 3ds Max 视口。
4. 中文工具窗口会自动打开，不需要安装第三方依赖。

也可以通过 3ds Max 的“脚本／运行脚本”选择同一个 `.mzp` 文件。

## 基本使用

1. 点击“拾取起点”，选择一个场景对象。插件使用对象的世界包围盒中心作为起点。
2. 点击“添加终点”，逐个选择一个或多个场景对象；同一对象不会重复加入。
3. 设置“平面面数”、宽度、路径噪波强度、噪波大小、Tiling 和随机种子；需要尖头轮廓时启用“面片两端平滑收尖”。
4. 根据需要启用“锁定起点”和“锁定终点”。
5. 点击“强制重新生成”创建一套新的独立 Editable Poly 闪电对象；每个终点对应一个对象，依次命名为 `LightningPlane001`、`LightningPlane002`……。
6. 在场景中选中一个已有闪电面片后调整参数，只会原位更新该对象并保留名称、层级和轴心；未选中的面片不会改变。
7. 需要改变某条已有面片的整体走向时，唯一选中它，再用“添加途经点”及上移、下移、移除、清空操作管理该面片自己的有序路径；需要圆滑转折时启用“途经点平滑过渡”，拖动强度滑条。需要更高平滑密度时可显式启用“平滑时允许额外加面”；两个以上途经点还会自动执行恒宽安全补面。之后移动途经点对象并重新选中所属面片，会在坐标确实变化时自动原位同步。

## 参数说明

- 平面面数：每条分支沿长度方向的基础四边面数。通常在额外加面关闭时它就是最终实际面数；两个以上途经点的恒宽安全补面是例外。设为 1 时，每条分支只有一个四边形，不能表现中段弯曲。
- 闪电宽度：带状面片的总宽度。
- 面片两端平滑收尖：将每条分支的起点和终点平滑缩小到正常宽度的 1%，中段保持原宽度。端点保留极小宽度以避免退化面；平面面数为 1 时只会得到一张窄而有效的四边面。
- 路径噪波强度：细噪波使中心线偏离起终点直线的幅度；它不等于轴向 Twist。
- 噪波大小：噪波整体尺寸倍率；越大时位移更明显，弯折也更宽缓。
- 噪波 Tiling：噪波重复频率；越大弯折越密集。
- 随机种子：相同控制对象、参数和种子会复现相同模型。
- 启用整段轴向扭转（Twist）：先在拉直的逻辑带上做类似 FFD 的累计旋转，再通过最小旋转平行运输框架映射回细噪波中心线，不给中心线增加额外 Noise，也不会让路径曲率放大角度。
- 轴向扭转分段：数值 `K` 将整条逻辑长度等分为 `K+1` 份；前 `K` 份是有效旋转段，最后一份用于终点保持或锁定回正，不改变“平面面数”。例如 2 段就是三等分。
- 轴向扭转角度：表示每个有效旋转段的角度增量；未锁定终点时总累计量为“分段数 × 角度”。每段使用恒定线性角速度，正负值代表相反方向，设为 0 等同于关闭。
- Twist 抗折叠：当当前平面面数不足以安全表达高角度旋转时，插件保留旧对象并提示增加面数或降低角度、分段、宽度或路径噪波，避免生成翻折和明显三角条纹。
- 动态布线：插件按路径曲率和 Twist 变化重新分配既有线环。无途经点路径仍可在必要时局部平滑收窄；含平滑途经点的内部路径禁止缩宽，两个以上途经点会在相邻转向区域自动安全补面，保持用户宽度。
- 锁定起点／终点：锁定处的路径噪波位移和轴向 Twist 角度精确归零，并在端点附近平滑衰减。
- 所选面片途经点：每个面片独立保存对象句柄和上次成功控制点坐标快照，路径按“起点 → 列表顺序 → 终点”精确经过各对象中心。移动途经点后重新选择所属面片时，只有检测到坐标变化才经过防抖原位更新；它不改变噪波、Twist 或其他参数，基础面数至少需要“途经点数量 + 1”。
- 启用途经点平滑过渡：默认关闭；开启后用相邻段共享切线的平滑曲线消除途经点处的硬折角，仍精确经过途经点中心。
- 途经点过渡强度：范围 `0–100` 的滑条，默认 `50`。`0` 与关闭完全等价，数值越高整体走向越圆滑；只改变基础路径，不改写噪波、Twist、宽度、收尖、锁端、种子或 UV 参数职责。
- 平滑时允许额外加面：默认关闭。开启后按每个途经点的转角与滑条强度，在进入侧末端和离开侧起始的局部过渡窗口中确定性增加平滑细节；新增线环不再平均分散到整段，`100` 时局部补面最多，共线路径不补面。两个以上途经点的恒宽安全补面始终按需启用，不受此开关关闭影响。面板同时显示基础面数与实际面数，每条分支实际面数上限为 `4000`。
- 途经点只控制导向：整条分支始终使用同一套全局噪波场和 Twist 累计角，不在途经点重置、衰减或旋转。插件在基础导向控制点层反向预补偿全局噪波，因此最终中心线仍精确经过途经点，但途经点处的噪波不会被强制压成零；自动加面只提高导向曲线的采样密度。
- 跨面折叠防护：除单个四边面检查外，还检查左右边界的前进方向与相邻截面反转风险；检测到扇形折返、截面翻转或边界倒退时保留旧模型并拒绝更新，同时允许正常 Twist 的连续旋转。
- 途经点局部重布线：新增线环集中在进入侧末端和离开侧起始；窗口内原有线环与新增线环统一均分，避免重合采样产生近零长度面。途经点平滑保持用户宽度，不再用缩窄截面掩盖急弯；等宽结果不安全时拒绝更新。
- 多途经点切线稳定：首尾同时局部加密的中间段按相邻实际边的单位方向公平分角；平行运输与 Twist 共用同一切线，第二个途经点不会因为两侧线环间距不同而额外扭转截面。

选中单个已有闪电面片后，数值、随机种子、锁定选项、两端收尖和轴向 Twist 参数会实时更新该对象的几何与 UV。拾取或更换控制点、添加或移除终点只影响下一次“强制重新生成”，不会修改已有面片。

强制重新生成与普通实时更新是两种不同操作：前者保留旧对象并新建一组，后者只原位更新场景中当前选中的单个插件面片。插件不再提供 Unity／Y-Up 轴向修改功能，也不会为新面片安装用于冻结旋转的 `Rotation List`。

## UV 与轴心

- UV 使用贴图通道 1。
- 每条分支按实际弧长从起点 `U=0` 展开至终点 `U=1`，宽度方向为 `V=0–1`。
- 每个独立分支对象都占满自身的 `0–1` UV，可复用同一张闪电贴图。
- 输出对象轴心始终位于公共起点中心。

## 开发验证

- `tools/build-package.ps1`：构建 `.mzp`。
- `tools/verify-package.ps1`：检查包结构与关键源码约束。
- `tests/smoke.ms`：验证低／中／高面数、多终点、四边面拓扑、UV、宽度、两端平滑收尖、细噪波、真正的轴向 Twist、中心线不变、端点锁定、实时防抖更新、轴心、控制点更新、失效引用和非法输入保护。
- 途经点专项断言覆盖对象级独立存储、按顺序精确经过中心、导向控制点噪波预补偿、全局噪波与 Twist 独立性、最终中心线一阶连续、共享切线平滑、滑条、可选局部自动加面、基础／实际面数、跨相邻面翻折拒绝、坐标快照选择同步、未变化不重建、失败不递归、连续四边面、UV、失败原子保留和旧面片兼容。
- `tests/gui-runner.ms`：在带所有权令牌的独立 3ds Max 2023 测试实例中运行核心测试。
- `tests/ui-bootstrap.ms` 与 `tests/ui-runner.ms`：从最终 `.mzp` 启动中文窗口，检查关键 UI 控件、轴向 Twist 开关和实时更新计时器；无测试实例令牌时不会运行或退出 Max。
- 最终实机结果保存在 `artifacts/gui-smoke-result.txt` 和 `artifacts/ui-smoke-final.txt`，两者均应为 `PASS`。
