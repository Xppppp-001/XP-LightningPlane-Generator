# XP模型扩宽工具：首尾宽度渐变设计

日期：2026-09-18。需求依据：根目录 REQUIREMENTS.md 的 R-046；目标：3ds Max 2023 中文版，独立扩宽工具 V1.2.0。

## 已确认的行为

用户希望条带前宽后窄或前窄后宽，保留原中线、弯曲走势与扭转方向。允许宽度和外轮廓变化。“等比”在本功能中表示同一截面的左右两侧采用同一个宽度倍率；长度方向的倍率线性渐变，不是沿世界轴整体缩放。

起点倍率 2、终点倍率 0.5 时，端部宽度分别是本次操作前对应截面宽度的 200% 与 50%。中间倍率按中线累计弧长插值；不把原有不等宽条带改成绝对等宽。

## 范围与方案取舍

本轮只增加首尾渐变，不改动闪电生成器。原统一倍率模式保留。已报告的紧弯重叠继续单独跟踪；不加入曲率限制、自动降倍、局部安全收窄、重叠拒绝或截面方向修正。

首尾识别可采用 UV 方向、顶点编号或用户显式选择。UV 可能缺失或反向，编号不表示用户心中的起点，因此采用显式选择端部横截面。范围可采用任意选中区间或完整对象；本版采用完整规则条带，避免多个不连续选区产生模糊的渐变范围。

## 中文交互

1. 唯一选择一个静态、独立的 Editable Poly 条带，进入边层级。
2. 选择用户认为是起点的端部横边（单侧或同排多根均可），点击“设置起点”。工具解析该完整端部截面并显示对象名和起点已设置状态，不修改几何或选择。
3. 用环形选择选齐整条条带的横截面，可只选一侧或同时选两侧。渐变模式通过现有横截面补齐逻辑得到所有排。
4. 填入“起点倍率”“终点倍率”，默认均为 1；点击“应用首尾渐变”。“交换首尾”交换两个输入倍率，起点标记本身不变。
5. 一次应用对应一项中文撤销记录。连续应用相对于每次点击前的宽度累乘；倍率 1 不能恢复初始模型。

统一倍率的“宽度倍率”和应用按钮继续保留，操作范围仍是原来的选中截面。渐变输入不改变统一倍率参数，两个模式不互相叠乘。

重新加载脚本关闭旧窗口，只保留一个新窗口并清空起点标记。标记只在当前窗口中保存同一节点、基础对象与端部顶点集合，不写入用户属性或后台回调。改选其他对象、替换基础对象、端部拓扑失效时必须重新设置起点；应用前总是重新核对完整网格及端部身份，不能仅信任缓存。保持拓扑的宽度修改后标记仍可使用。

## 几何计算与校验

先复用完整横截面解析，再依据相邻四边面的纵向连接建立截面邻接链；不按世界轴、编号或 UV 猜测首尾。渐变模式要求排覆盖对象所有顶点和面、宽度列数一致、两个端部且内部每排有两个唯一邻排，每个面属于两个相邻截面。拒绝漏排、纵横混选、分叉、闭环、非流形、非四边面、不规则网格与失效起点。这些是输入有效性检查，不是重叠限制。

从用户起点按链序遍历至另一个端部，取得原始中心 C：奇数顶点排采用真实中间顶点，偶数顶点排采用外侧端点中点。将中心乘以节点 objectTransform 得到世界位置；计算相邻世界中心距离并累计为 s，总长度为 S。零长度相邻中心或非法坐标在写入前拒绝。

每排使用 t=s/S，倍率 f=起点倍率×(1-t)+终点倍率×t。首尾直接采用对应输入值，避免累积误差；如果两端倍率相同，所有排直接采用该值。局部坐标中计算新顶点 Q=C+(P-C)×f；真实中线顶点直接保留原 P，避免浮点扰动。所有点通过检查后一次批量写入，不使用软选择。

保持节点、名称、父级、变换、轴心、材质、UV 数据、面连接、面数、原边选择与其他对象不变。不修改截面方向、中心点或中线长度。外侧边界长度及三角化后的贴图显示会随宽度变形，不能承诺保持原视觉结果。

## 原子提交与兼容

继续拒绝修改器、共享实例基础对象和非 Editable Poly，不自动转换或塌陷。合法倍率沿用 0.01～100，不允许零宽退化截面。

完整解析和坐标计划必须在 Undo 与写入前完成。双端 1 返回不变状态且不写入。一次成功应用只产生一项 Undo；写入失败尝试用已保存坐标恢复并报告结果。无需第三方运行时，独立 .ms 和 .mzp run/drop 同步；保留旧版本包追溯。
